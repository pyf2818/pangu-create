# 产出质量门（Output Quality Gate）

> 结构分高 ≠ 作品好看。实证：threejs-web 自动评分 81/81、web-game-craft 进化到 86.3，但光刻机 demo、像素游戏、知识卡片成品仍被用户判「效果一般」。根因不是引擎写得差，是**尺子量错了对象**——rubric 量 SKILL.md 的文本结构，用户看的是产物。
>
> 本文件把「产出好不好」变成三道不可自我满足的闸门：**参照物 → 工艺参数 → 盲评对比**。适用：产出型 skill、观感负重（视频/3D/游戏/页面/卡片/文档/小说/PPT）。

---

## 关 1：参照物关（Reference Gate）

**目的**：先定义「好」长什么样，再动手。没有参照物的视觉设计 = 从零发明审美，必然落回 AI 默认俗手。

| 项 | 要求 | 不合格信号 |
|----|------|-----------|
| 参照物类型 | 2-3 个**同类顶级成品**（获奖作品/上线产品/名家作品/公认课程 demo）——不是同类 skill 的源码，不是本 skill 的默认模板 | 只读了同类 SKILL.md，或拿自己的模板当参照 |
| 拆解粒度 | 逐件拆成**参数**：构图/相机、色彩角色 + 对比度、字阶与字重、间距系统、材质/光比、动效时长与曲线、声音/节奏 | 只写「好看/高级/有氛围」这类形容词 |
| 落盘 | `references/art-direction.md`：参照物清单 + 参数拆解表 + 差距清单 | 读完就丢，没落盘 |

**硬性规则**：

1. 每个负重观感维度至少 1 个参照物支撑；找不到 → 诚实标注「无美学标杆，观感为框架级」，不许假装。
2. F1 的「美学标杆轨」从「观感负重时必做」升级为**产出型 skill 强制项**。
3. 参照物只提供**方向与参数**，禁止照抄成品；禁止把参照物的品牌元素/独有图形直接搬进产出。

**差距清单格式**（参照物 vs 我们当前最好产出，至少 5 条）：

| # | 差距 | 参照物参数 | 我们当前 | 改法（参数级） |
|---|------|-----------|---------|---------------|
| 1 | 画面层次 | 前景/中景/背景三层，光比 3:1 | 全在一個平面，光比 1:1.2 | 主光强度 ×2.5、加背光轮廓、远景压暗 30% |

## 关 2：工艺参数关（Craft Gate）

**目的**：把「品味」翻译成可直接执行的数字。形容词不可执行，参数可执行。

产出型 skill 的 `references/art-direction.md` 必须写死以下参数（按形态取用，至少 8 项）：

| 类别 | 必须给出 | 示例（仅供参考，不是默认值） |
|------|---------|------------------------------|
| 色彩 | 5-6 个 hex + 角色（底/墨/主/次/点缀/线）+ 正文与背景对比度 ≥4.5:1 | `#0E1A1D / #E8EDE9 / #C9A227 …` |
| 排版 | 字阶比（如 1.25）、字重层级 ≤3、行高/字距、正文最大行宽 | 标题 64px / 正文 18px / 行高 1.6 |
| 间距 | 基准单位（4/8pt）+ 区块呼吸值 | 区块 96px、卡片内 24px |
| 构图 | 每屏焦点位置、留白比例、三分法/中心构图选择及理由 | 焦点偏左上 1/3，留白 40% |
| 材质/光影 | 粗糙度/金属度区间、光比、阴影软硬、是否有 IBL/反射 | key:fill:rim = 3:1:1.5 |
| 动效 | 曲线（cubic 族）、时长区间、错峰间隔、定格时长 | 入场 320-480ms outCubic，定格 ≥1s |
| 声音 | 触发点、音色、响度目标、留白 | 命中音 80ms，BGM -18 LUFS |
| 招牌手法 | **≥2 个非默认、可一眼指出的手法**（不是「加粒子/加雾」这类通用配方） | 扫描揭示 + 体积光柱色散；字块被光斑逐字点亮 |

**判定**：把参数表贴在产出旁逐项对照，缺一项 = 关 2 不过。参数必须来自关 1 的参照物或实测标定，不许拍脑袋。

**招牌手法 vs 配方数量的区别**：

| 伪通过 | 为什么不算 |
|--------|-----------|
| 「用了 ≥2 个配方库效果」 | 粒子/雾/辉光是任何模板都能加的量产件；数量不等于辨识度 |
| 「配色统一」 | 统一不等于好看；暗底 + 单一青蓝也统一，但那是 AI 默认皮肤 |
| 「有视觉锚点」 | 一个色块也叫锚点；锚点必须承担信息或构图职责 |

## 关 3：盲评对比关（Blind Compare Gate）

**目的**：让「作品分」不再由作者自己说了算。

### 3.1 变体先行（禁止第一版直接交付）

同一 brief 产出 **2-3 个真正不同的美术方向**（在构图/色板/字体/材质/节奏等关键轴上不同，不许换皮），并排展示给用户选择或合并。第一版即交付 = 硬性失败。

### 3.2 独立盲评

- judge 不知道哪件是我们产出、哪件是参照物/基线；只回答「哪件更像可发布作品」+ 胜负 margin + **≥5 条差距**
- 3 judge 奇数多数决；输给参照物 = 软性失败，必须进入下一轮迭代
- 无独立子 agent → 标 `self_eval`，**不得 keep、不得宣称「达到发布级」**（见 testing.md §10）
- **运行时污染防线**（csvviz-forge 实测坑）：①盲评页面判定必须**串行执行**——并行 browser agent 共享浏览器实例时 network/console 记录互相串台，曾把零外联页面误判为「有 jsdelivr 请求」；②页面 URL 统一带 `?nocache=<时间戳>` 防浏览器缓存旧版，把「修复无效」误判出来；③「有无外联」的最终仲裁 = 静态 grep 产物源码 + 独立复测，不采信共享会话的 network 面板

### 3.3 反模板测试

把产出与 skill 默认模板/基线并排，5 秒内必须能指出 **≥3 处实质差异**（构图、色板、字体、材质、节奏）。指不出 = 模板换皮，硬性失败，回关 1 重定美术方向。

### 3.4 三秒测试

把首屏截图给「第一次看到的用户」看 3 秒，问：这是什么？亮点在哪？答不出 = 视觉锚点失败（锚点没有承担注意力职责），硬性失败。

## 迭代纪律（产出型 ≥3 轮）

```
轮 1：按参数表做第一版 → 截图/录制 → 与参照物并排，列 ≥5 条差距
轮 2：按差距清单改 ≥3 个参数（不是加新元素）→ 再比
轮 3：招牌手法打磨 + 反模板测试 + 三秒测试 → 盲评
```

- 文本型 skill 维持 2 轮上限；**产出型从 2 轮提高到 3 轮**——视觉工艺的边际提升在第三轮才出现
- 每轮必须记录：改了哪些参数、为什么、改前/改后截图或帧
- 只加元素不调参 = 不算一轮（「加粒子」不是工艺改进）
- 3 轮后仍输给参照物 → 在诚实边界标注薄弱维度，交付当前最优；不许无限打磨

---

## 失败分级

| 情形 | 级别 | 处置 |
|------|------|------|
| 盲评输给参照物 | 软性 | 进入下一轮，按差距清单改参数 |
| 无法指出 ≥3 处模板差异 | **硬性** | 重做美术方向（回关 1） |
| 三秒测试答不出这是什么 | **硬性** | 重做视觉锚点与首屏构图 |
| 参数表缺失或只有形容词 | **硬性** | 回关 2 补齐，不许交付 |
| 无参照物且领域确有标杆 | **硬性** | 回 F1 补美学标杆轨 |
